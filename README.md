**Projeto de Capacitação Front-End**
Este projeto foi desenvolvido durante a capacitação de Front-End da Ecomp, com o objetivo de colocar em prática os conhecimentos adquiridos ao longo do curso.

**Tecnologias utilizadas para o desenvolvimento do site:**
- HTML
- CSS
- JavaScript
- Tailwind CSS
- React
- API

Durante o desenvolvimento, pude desenvolver habilidades como a criação de interfaces, componentização, estilização e a utilização de uma API.
